API یکی از پرکاربردترین اصطلاحاتی است که در دنیای نرم‌افزار می‌شنوید، اما خیلی‌ها معنای دقیق آن را نمی‌دانند. خبر خوب این است که مفهوم آن بسیار ساده‌تر از چیزی است که به‌نظر می‌رسد.

## تشبیه گارسون رستوران

API مخفف Application Programming Interface است، اما بهترین راه فهمیدنش یک تشبیه است: تصور کنید در رستوران نشسته‌اید. شما مستقیماً وارد آشپزخانه نمی‌شوید تا غذا را بردارید؛ به‌جای آن، به گارسون سفارش می‌دهید، گارسون سفارش را به آشپزخانه می‌برد، و غذای آماده را برایتان می‌آورد.

API دقیقاً همین نقش گارسون را بین دو نرم‌افزار ایفا می‌کند: یک برنامه (مثلاً اپلیکیشن موبایل شما) درخواستی می‌فرستد، API آن درخواست را به سیستم دیگر (مثلاً سرور یک بانک) منتقل می‌کند، و پاسخ را برمی‌گرداند — بدون اینکه برنامه‌ی شما نیاز داشته باشد بداند داخل آن سیستم دیگر دقیقاً چه خبر است.

## یک مثال واقعی: اپلیکیشن هواشناسی

وقتی اپلیکیشن هواشناسی گوشی‌تان را باز می‌کنید، آن اپلیکیشن خودش داده‌ی هواشناسی را اندازه نمی‌گیرد. به‌جای آن، از طریق یک API به یک سرویس هواشناسی متصل می‌شود، درخواست «وضعیت هوای فلان شهر» را می‌فرستد، و داده را دریافت و نمایش می‌دهد.

## چرا API این‌قدر مهم است؟

- **جداسازی مسئولیت‌ها:** هر سیستم می‌تواند مستقل توسعه یابد، به شرطی که «قرارداد» API را رعایت کند.
- **استفاده مجدد:** یک سرویس (مثل درگاه پرداخت) می‌تواند توسط ده‌ها اپلیکیشن مختلف استفاده شود، بدون اینکه هرکدام مجبور باشند از صفر سیستم پرداخت بسازند.
- **یکپارچه‌سازی سامانه‌ها:** در کسب‌وکارها، API این امکان را می‌دهد که مثلاً سیستم فروش، انبار و حسابداری بدون ورود دستی اطلاعات، خودکار با هم داده رد و بدل کنند.

## چند اصطلاح مرتبط که زیاد می‌شنوید

- **REST API:** رایج‌ترین سبک طراحی API، مبتنی بر درخواست‌های HTTP (مثل GET برای دریافت داده و POST برای ارسال داده).
- **JSON:** فرمت متنی سبکی که اغلب API‌ها برای تبادل داده از آن استفاده می‌کنند؛ خوانا برای انسان و ماشین هر دو.
- **Endpoint:** یک آدرس مشخص در API که یک عملیات خاص را انجام می‌دهد (مثلاً `/users` برای دریافت لیست کاربران).

## جمع‌بندی

API پلی است که به دو نرم‌افزار اجازه می‌دهد بدون دانستن جزئیات داخلی یکدیگر، با هم صحبت کنند. از اپلیکیشن‌های موبایل روزمره گرفته تا سیستم‌های پیچیده‌ی سازمانی، تقریباً هیچ نرم‌افزار مدرنی بدون API قابل تصور نیست.
